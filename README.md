# 🛍️ Customer Shopping Behaviour Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behaviour to understand purchasing patterns, customer preferences, spending habits, and product performance.

The project follows a practical data analytics workflow using **Python, Pandas, and PostgreSQL**. The raw customer dataset is cleaned, transformed, and analyzed to answer real-world business questions using SQL.

The main objective is to convert raw customer data into meaningful insights that can support better business decisions.

## 🎯 Project Objectives

- Understand customer purchasing patterns.
- Analyze customer spending behaviour.
- Identify popular products and product categories.
- Explore customer loyalty and subscription behaviour.
- Examine the relationship between discounts and purchase amounts.
- Analyze revenue contribution across customer segments.
- Practice data cleaning, feature engineering, and SQL-based business analysis.

## 📂 Dataset

The project uses a customer shopping behaviour dataset containing **3,900 customer purchase records** and 18 original columns.

The dataset includes information such as:

- Customer ID
- Age and Gender
- Item Purchased
- Category
- Purchase Amount
- Location
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Previous Purchases
- Payment Method
- Frequency of Purchases

## 🔄 Project Workflow

### 1. Data Import and Exploration – Python

- Imported the dataset using Pandas.
- Explored the dataset using `head()`, `info()`, and `describe()`.
- Checked the dataset structure and data types.
- Identified missing values and understood the data.

### 2. Data Cleaning – Pandas

- Handled missing values in the Review Rating column.
- Filled missing review ratings using the median rating of the respective product category.
- Standardized column names for easier analysis.
- Checked the dataset for consistency.

### 3. Feature Engineering – Python

Created new analytical features to improve business analysis:

- **Age Group:** Segmented customers into different age groups using quantile-based categorization.
- **Purchase Frequency Days:** Converted purchase frequency categories into numerical day intervals.

Also identified and removed a redundant column after checking that the discount and promo code columns contained matching values.

### 4. Database Integration – PostgreSQL

- Created a PostgreSQL database named `customer_behaviour`.
- Created and populated the `customer` table.
- Connected Python to PostgreSQL using SQLAlchemy and psycopg2.
- Loaded the cleaned dataset into PostgreSQL for further analysis.

### 5. Business Analysis – SQL

Used SQL queries to answer important business questions, including:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but spent more than the average purchase amount?
3. Which products have the highest average review ratings?
4. How do average purchase amounts differ between standard and express shipping?
5. Do subscribed customers spend more than non-subscribed customers?
6. Which products have the highest percentage of discounted purchases?
7. How can customers be segmented into new, returning, and loyal customers?
8. What are the top three most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Install Required Python Libraries

```bash
pip install pandas sqlalchemy psycopg2-binary jupyter
```

### 3. Open the Jupyter Notebook

```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb`.

### 4. Configure PostgreSQL

- Install PostgreSQL.
- Create a database named `customer_behaviour`.
- Update the database connection details in the notebook.
- Run the notebook cells to clean the data and upload it to PostgreSQL.

**Important:** Do not upload your PostgreSQL password or other sensitive credentials to GitHub.

### 5. Run SQL Queries

Open `customer_behaviour_analysis.sql` in pgAdmin or another PostgreSQL SQL editor.

Execute the queries to explore customer behaviour and answer the business questions.
